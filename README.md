# Личный кабинет — macOS

Отдельный репозиторий десктоп-приложения **«Личный кабинет»** для macOS (Electron).

## Сборка
- Автоматически: GitHub Actions **«Build macOS»** (запускается по пушу в `main` или вручную по кнопке).
- Результат публикуется в Release `biotime-mac-latest` (`.dmg` — установка, `.zip` — автообновление).
- Локально (на Mac): `npm ci` и `npx electron-builder --mac --publish never`.

Подпись/нотаризация не выполняются (нет учётки Apple Developer) — файлы открываются через «Правый клик ▸ Открыть».
